## 人工测试与审查确认

用户反馈已发布 1.1.0 功能正常；本轮自动化实际确认了升级、连接与轮询、两页加载和图标显示。以下清单是审核要求的**人工确认项**，不因 AI 检查、单元测试通过或截图完成而自动打勾。由实际执行者记录日期、版本、结果和发现的问题。

- [ ] 人工检查主要代码路径，重点关注 Token 保密、权限控制、出站地址检查、持久化与去重、附件替换及停用清理。
- [ ] 安装/升级后启用、配置、停用、重启正常；升级不会丢失配置及内容。
- [ ] 在专用频道和授权私聊验证文字、图片、相册发布及原位编辑。
- [ ] 验证 `/redo`、`/rm`、相册非首成员操作，以及未授权来源不会被处理。
- [ ] 验证可见性、审核、标签、前后缀、来源链接及编辑保留人工管理字段。
- [ ] 验证反馈/清理权限不足、附件失败及任务重试，确认不会重复发布或误删内容。
- [ ] 复核 AI 生成代码及素材来源、许可与可分发权利；AI 参与不替代开发者责任。

历史验证记录见 [PR #1 本地验收](plans/2026-10-27-pr1-windows-validation.md)。其中包含旧集成脚本断言与新命令反馈契约不一致的问题，不应宣称该脚本完整通过。涉及发送、编辑、删除的人工测试仅在专用测试内容上执行，不操作生产内容。
