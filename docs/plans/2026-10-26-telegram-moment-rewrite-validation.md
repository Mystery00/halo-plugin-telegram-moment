## 真实 Halo + 模拟 Telegram

环境为独立 Halo 2.22.14 容器（端口 18090），分别安装官方瞬间 1.15.0 和 1.16.0。Telegram API 使用隔离网络中的 Python 模拟服务，未使用真实 Token。

两个版本均通过：

- 安装、启用、升级插件，配置后启动 Bot。
- 无 `from` 的频道文字发布，编辑保持原 Moment 名称。
- 重复 Update 不重复创建；`/redo` 保持原记录。
- 两张图片相册，第二张 caption 作为说明；下载后的 PNG 内容与类型正确。
- 不带 media_group_id 的成员编辑仍更新原相册。
- 回复非首成员执行 `/rm`，整组删除。
- 精确屏蔽 hashtag。
- 文件服务返回 500 时不发布空瞬间；第 5 次失败后保留任务，修复服务并手动重试成功。
- 关闭回复时没有调用模拟 `sendMessage`。
- 接收游标已持久化后停止并重启 Bot，待处理相册继续发布。
- 匿名访问管理日志被拒绝；1.15.0 下额外确认公开瞬间 API 可以读到新发布内容。

## 浏览器检查与回归

使用可见 agent-browser 实际打开 Halo 控制台，检查状态、失败列表、日志、配置入口、停止以及手动重试。最终管理页显示零待处理、零失败；配置页 Token 使用密码框。

真实环境额外发现并修复：

1. Halo 本地附件处理器返回不可变 annotations，回调必须复制后修改。
2. Controller 路径参数缺少显式名称，手动重试返回 500；补充 HTTP 级测试后修复。

独立审查发现并修复：未知删除命令的中间 PUBLISH 落盘窗口；已提交附件在后续编辑失败时被误清理的窗口。上述问题均有先失败、后通过的回归测试。
