# 插件 Logo 更新

## 设计与素材

- 对应插件：Telegram 瞬间同步，内部 ID 为 `telegram-moment`。
- 设计表达：以纸飞机、图片内容卡片和连接弧线表现消息与图文瞬间之间的同步关系。
- 视觉：青蓝至深青渐变圆角底板，白色和浅薄荷色主体，不含文字，适用于插件列表的小尺寸展示。
- 生成方式：使用 OpenAI 内置 imagegen 生图工具生成全新 PNG，未使用 CLI 或旧 SVG 转换。
- 资源路径：`src/main/resources/logo.png`；实际输出为 1254 × 1254 像素，32 位 RGBA，外侧具有透明通道。直接使用生成文件，未额外缩放或修改像素。
- 素材来源：根据本项目功能专门生成，随仓库按 GPL-3.0 分发，不作为 Telegram 或 Halo 官方品牌标识。

## 生成提示词（中文记录）

为独立开源 Halo 插件“Telegram 瞬间同步”设计一个完成版应用图标。插件将 Telegram 频道、私聊、照片与相册同步为博客短内容。生成一个方形图标，将向上飞行的纸飞机、圆角内容或照片卡片与一条流畅连接弧线整合成统一符号，表达消息成为被保存的瞬间。白色和浅薄荷色主体搭配深青到青蓝的圆角渐变底板，底板居中约占画布 88%，外侧真实透明。采用简洁几何形状、清晰边缘、均衡留白，在 32 像素下仍能辨认。不要文字、字母、数字、水印、效果样机、额外徽章、勾选符号、照片或三维效果；不要照搬 Telegram 官方圆形纸飞机图标或 Halo 品牌。只生成一个最终图标，不生成多方案拼图。请求尺寸为 1024 × 1024，实际保存尺寸以上方文件检查结果为准。
