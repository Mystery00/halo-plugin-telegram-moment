# 高级配置与排错

基本安装、常用选项和命令见 [README](../README.md)。

## 自定义 API Endpoint

留空使用 `https://api.telegram.org`。自定义代理必须同时支持 Bot API 和 `/file/bot...` 文件下载路径。端点可包含由字母、数字、下划线和短横线组成的路径前缀，仅支持 HTTPS、443 端口，不跟随重定向。不要把 Token 写在端点中。

代理能接触 Bot Token 和消息，请仅使用自己管理或信任的服务。

### 私网与 CGNAT 代理

默认只连接公网地址。如需使用可信私网代理，在「可信端点地址」中填写精确规则，例如：

```text
proxy.example.com=100.64.0.7
```

替换成实际代理域名和 IP；每行或逗号分隔一个规则，最多 32 条。支持 IPv4 私网、CGNAT 和 IPv6 ULA，不支持通配符、CIDR、环回、链路本地或其他保留地址。所有 DNS 结果都必须是公网或被该域名的规则授权，否则连接会被拒绝。TLS 证书校验保持启用。

日志出现 `blocked by endpoint address policy` 时，检查其中的数字地址及 DNS 配置；不要仅因为地址出现在解析结果中就信任它。保存配置后重启 Bot 生效。

## 相册、标签与来源链接

- 相册按消息 ID 排序，使用第一个非空说明。聚合延迟默认 3 秒，可配置 1–60 秒；迟到成员会更新同一瞬间。
- 文本与图片说明支持常用格式、链接和 hashtag，屏蔽标签按完整 hashtag 匹配。
- 默认标签与正文 hashtag 去重合并。前后缀按纯文本处理，其中的 `#` 不自动成为标签；统一标签请使用「默认附加标签」。
- 相册来源链接指向首条已记录消息；公开频道优先使用用户名链接，否则使用合法的频道数字链接。私聊不生成链接，私有频道链接仍需要频道访问权限。
- `/redo` 使用回复目标的当前内容，只更新对应相册成员，保留其他已记录成员；`/rm` 删除已知相册整组瞬间及相关附件。
- 图片说明中的 `/rm` 等文字是普通内容，不作为命令执行。未知命令、缺少目标等情况不会发布为瞬间；发给其他 Bot 的命令会忽略。
- 找不到已同步瞬间时，删除命令会明确提示无法定位。旧版本未保存的相册关系不能自动补齐；关联不完整时会保护原内容、拒绝覆盖。不要手工删除同步记录或来源注解。

## 回执与消息清理

普通消息回执默认关闭，需在频道或私聊配置中主动开启。命令会独立反馈使用提示或执行结果，请给 Bot 相应发送权限。

「成功执行后清理命令消息」默认开启，仅清理成功的 `/rm`、`/redo` 命令；提示与失败命令保留。「删除瞬间时同时删除 Telegram 原消息」默认关闭，开启后仅在 `/rm` 成功时清理已记录的源消息；`/redo` 不删除源消息。

反馈和清理任务会保存并有限重试，失败不会重新执行已经完成的 Halo 操作。Telegram 删除权限、消息年龄等限制可能导致清理失败。

## 日志与故障定位

管理页显示运行状态、最近连接、发布时间和失败原因，每 10 秒刷新。开启日志记录并重启 Bot 后，可在页面查看日志；需排查每次轮询时，再开启调试模式。

| 日志阶段 | 含义 |
| --- | --- |
| Connection | 身份验证和连接恢复 |
| Polling | 轮询数量、耗时、心跳与重试 |
| Receive | 消息接收、入队或忽略原因 |
| Media | 媒体下载与上传 |
| Sync | 发布、编辑与删除结果 |

可用 `update`、`message`、`task` 标识关联处理过程。正常空轮询每分钟记录一次心跳，调试模式会记录逐次轮询。

| 错误或现象 | 检查方向 |
| --- | --- |
| 401 | Token 是否有效，Secret 中是否有正确的 `token` 键 |
| 403 | Bot 是否具有发送或删除等必要权限 |
| 409 | 是否有其他程序长轮询同一 Bot，或配置了 webhook |
| 429 | 按提示等待限流时间，不要频繁重启 |
| DNS、TLS 或超时 | Halo 服务器的解析、证书、网络和代理配置 |
| 附件下载失败 | 代理是否支持文件下载路径，媒体是否超出限制 |
| 发布失败 | 瞬间是否启用，发布者和存储策略是否存在 |

发布失败会自动进行有限重试；仍失败时保留任务，修复原因后可手动重试。切换 Bot 不会让新 Bot 处理旧 Bot 的任务。长时间停用后，Telegram 已不再保留的历史消息无法补齐。

## 数据保留与卸载

- **数据流向**：Halo 主动从 Telegram 或指定代理接收消息、下载媒体，再存入 Halo 和所选附件存储。普通回执或命令反馈会向 Telegram 发送处理结果，删除请求按配置执行。插件没有遥测或第三方统计。
- **保存内容**：Bot Secret、插件配置、接收游标、消息与相册映射、命令及清理任务、瞬间和附件保存在 Halo 中。消息按可见性配置发布，同步记录为支持后续编辑和删除而持续保留。
- **日志**：页面内存日志最多保留 2 小时、500 条，关闭实例后丢失。日志包含消息 ID、任务 ID 和处理结果，不保存完整消息或 Token；服务日志保留时间由 Halo 部署环境决定。
- **升级与降级**：先备份数据库和附件。旧版明文 Token 在 Bot 启动时迁入 Secret，验证成功后才移除旧字段；失败时停止启动并提示检查。旧版程序无法直接使用新引用，降级需从备份恢复匹配配置。
- **停用与卸载**：停用只停止接收，不删除已有内容。插件卸载不会主动删除 Secret、瞬间和附件；Halo 对扩展数据的清理由卸载选项决定。需要彻底清理时，先备份、停用插件，再在 Halo 后台检查并删除相关内容、配置及不再引用的 Secret，不要删除其他应用共用的数据。

建议使用专用 Bot、限定频道 ID，只授予必要权限。管理权限不额外授予 Secret 读取权限；反馈问题时不要公开 Token、Secret 内容或私人消息。
